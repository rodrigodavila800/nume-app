# Manifesto do Agente — ponteiro

O manifesto canônico deste projeto agora é o **`AGENTS.md` na raiz** do repositório (`../AGENTS.md`). Ele é lido por Claude Code (via `CLAUDE.md`) e pelo Antigravity/Gemini.

Esta pasta (`.agents/`) guarda apenas:

- `rules/` — regras globais (multi-tenancy, DevSecOps, diretrizes da Sofi, design web).
- `skills/` — uma skill por módulo (`core-saas`, `portal-cliente`, `producoes-videos`, `sofi-ia`, `laravel-ai-sdk`, `financeiro-stripe`, `analytics-telemetria`).

Não duplique aqui o que já está no `AGENTS.md` da raiz, para os dois não divergirem.
